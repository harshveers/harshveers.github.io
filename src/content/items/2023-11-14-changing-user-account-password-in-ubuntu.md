Changing your user account password in Ubuntu is fairly simple...
1) Open your terminal with Ctrl+Alt+t or from 'application menu>Accessories>Terminal'.
2) Type passwd
Type your current password
And then type your new password and then retype it. :)
![Ubuntu terminal running passwd: it asks for the current password, then the new one twice, and reports the password was updated successfully](../../assets/posts/changing-user-account-password-in-ubuntu/1.png)
